# Recipes

A single pattern rarely builds a whole feature. Each recipe takes one feature and shows how several patterns combine to build it: what job each pattern does, how they connect, a combined Unity C# example, and what goes wrong where they meet.

::: warning Build the simple version first
Recipes show where a feature **can** end up at scale, not where to start. Begin with plain code and use a recipe as a map when that starts to strain. See [Keep It Simple](../keep-it-simple).
:::

Pattern chips link to their pages. Grey chips and recipes marked **planned** are not written yet.
