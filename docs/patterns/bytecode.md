# Bytecode

> Encode behaviour as instructions for a small virtual machine, so it can be data.

**Category:** Behavioral & Communication

## Problem

A spell-crafting game lets players and modders define new spells: "deal 10 damage to the target, heal yourself for half of that, and if your health is below 30, play the panic sound". The spells must be data, so they can be downloaded, shared and modded, but they need *logic*: arithmetic, conditions, calls into the game. Shipping C# code is impossible (modders cannot compile it, it cannot be sandboxed, and IL2CPP platforms cannot load new code). An [interpreted tree](./interpreter) works, but is slow for thousands of executions per frame, and awkward to serialise.

## Solution

Define a tiny **virtual machine** with a fixed set of **instructions**, and represent behaviour as a flat **array of those instructions**: bytecode.

- **Instructions** are simple: push a value, add, compare, jump if zero, get the target's health, deal damage, play a sound.
- The VM is a loop with a `switch` over opcodes and a **stack** for intermediate values. It executes instruction after instruction.
- Bytecode is **data**: bytes in an asset, a file or a network message. It can be generated by a compiler from a friendlier format (a text language, a visual graph).
- The VM is a **sandbox**: bytecode can only do what instructions allow. There is no file access, no arbitrary engine calls, and no infinite loops if you cap the instruction count.

## Pseudocode

```text
// Instructions: one byte each, some followed by an operand.
PUSH value | ADD SUB MUL DIV | LESS | JUMP_IF_ZERO target | JUMP target
GET_HEALTH | DAMAGE | HEAL | PLAY_SOUND | END

SpellApi:                   // the only ways a spell can touch the game
    get_health(who), damage(who, amount), heal(who, amount), play_sound(id)

run(code, api):
    stack ← empty           // at most 64 values
    pc ← 0                  // index of the next byte to read
    executed ← 0
    while pc < length of code:
        executed ← executed + 1
        if executed > 10 000: fail "ran too long"   // sandbox limit
        op ← code[pc]; pc ← pc + 1
        switch op:
            PUSH:         push the float at code[pc]; pc ← pc + 4
            ADD, SUB, MUL, DIV, LESS:
                          b ← pop; a ← pop; push (a op b)   // LESS → 1 or 0
            JUMP_IF_ZERO: target ← operand; pc ← pc + 2
                          if pop = 0: pc ← target
            JUMP:         pc ← operand
            GET_HEALTH:   push api.get_health(pop)
            DAMAGE, HEAL: amount ← pop; who ← pop; api.damage/heal(who, amount)
            PLAY_SOUND:   api.play_sound(pop)
            END:          return
            otherwise:    fail "bad opcode"
        // popping an empty stack or pushing a full one also fails

// "Deal 10 to the target, heal self 5, if own health < 30 play sound 7"
// (who: 0 = caster, 1 = target)
PUSH 1, PUSH 10, DAMAGE
PUSH 0, PUSH 5,  HEAL
PUSH 0, GET_HEALTH, PUSH 30, LESS
JUMP_IF_ZERO end        // the assembler patches in where "end" is
PUSH 7, PLAY_SOUND
end: END
```

## Example

### Core: a small stack-based VM

The VM has no engine types: the game is reachable only through the `SpellApi` it is given, and fixed stack and instruction limits sandbox it.

::: code-group

```csharp [Unity (C#)]
using System;
using System.Collections.Generic;

public enum Op : byte
{
    Push,          // next 4 bytes: a float literal
    Add, Sub, Mul, Div,
    Less,          // pop b, a → push (a < b ? 1 : 0)
    JumpIfZero,    // next 2 bytes: target offset; pop condition
    Jump,          // next 2 bytes: target offset
    GetHealth,     // pop who (0 = caster, 1 = target) → push health
    Damage,        // pop amount, who
    Heal,          // pop amount, who
    PlaySound,     // pop sound id
    End,
}

public interface ISpellApi                 // the ONLY things bytecode can do in the game
{
    float GetHealth(int who);
    void Damage(int who, float amount);
    void Heal(int who, float amount);
    void PlaySound(int soundId);
}

public static class SpellVM
{
    const int MaxStack = 64, MaxInstructions = 10_000;   // sandbox limits

    public static void Run(byte[] code, ISpellApi api)
    {
        var stack = new float[MaxStack];
        int sp = 0, pc = 0, executed = 0;

        float Pop() => sp > 0 ? stack[--sp] : throw new InvalidOperationException("Stack underflow");
        void Push(float v) { if (sp == MaxStack) throw new InvalidOperationException("Stack overflow"); stack[sp++] = v; }

        while (pc < code.Length)
        {
            if (++executed > MaxInstructions) throw new InvalidOperationException("Spell ran too long");

            var op = (Op)code[pc++];
            switch (op)
            {
                case Op.Push:       Push(BitConverter.ToSingle(code, pc)); pc += 4; break;
                case Op.Add:        { float b = Pop(), a = Pop(); Push(a + b); break; }
                case Op.Sub:        { float b = Pop(), a = Pop(); Push(a - b); break; }
                case Op.Mul:        { float b = Pop(), a = Pop(); Push(a * b); break; }
                case Op.Div:        { float b = Pop(), a = Pop(); Push(b == 0 ? 0 : a / b); break; }
                case Op.Less:       { float b = Pop(), a = Pop(); Push(a < b ? 1 : 0); break; }
                case Op.JumpIfZero: { int target = BitConverter.ToUInt16(code, pc); pc += 2; if (Pop() == 0) pc = target; break; }
                case Op.Jump:       pc = BitConverter.ToUInt16(code, pc); break;
                case Op.GetHealth:  Push(api.GetHealth((int)Pop())); break;
                case Op.Damage:     { float amount = Pop(); api.Damage((int)Pop(), amount); break; }
                case Op.Heal:       { float amount = Pop(); api.Heal((int)Pop(), amount); break; }
                case Op.PlaySound:  api.PlaySound((int)Pop()); break;
                case Op.End:        return;
                default:            throw new InvalidOperationException($"Bad opcode {op} at {pc - 1}");
            }
        }
    }
}
```

```gdscript [Godot (GDScript)]
# spell_vm.gd
class_name SpellVM
extends RefCounted

enum Op {
	PUSH,          # next 4 bytes: a float literal
	ADD, SUB, MUL, DIV,
	LESS,          # pop b, a → push (a < b ? 1 : 0)
	JUMP_IF_ZERO,  # next 2 bytes: target offset; pop condition
	JUMP,          # next 2 bytes: target offset
	GET_HEALTH,    # pop who → push health
	DAMAGE,        # pop amount, who
	HEAL,          # pop amount, who
	PLAY_SOUND,    # pop sound id
	END,
}

const MAX_STACK := 64
const MAX_INSTRUCTIONS := 10_000  # sandbox limits

var _stack: Array[float] = []
var _error := ""


## Returns "" on success, or an error message: GDScript has no exceptions.
func run(code: PackedByteArray, api: SpellApi) -> String:
	_stack.clear()
	_error = ""
	var pc := 0
	var executed := 0

	while pc < code.size() and _error == "":
		executed += 1
		if executed > MAX_INSTRUCTIONS:
			return "Spell ran too long"

		var op := code[pc]
		pc += 1
		match op:
			Op.PUSH:
				_push(code.decode_float(pc))
				pc += 4
			Op.ADD, Op.SUB, Op.MUL, Op.DIV, Op.LESS:
				var b := _pop()
				var a := _pop()
				_push(_arithmetic(op, a, b))
			Op.JUMP_IF_ZERO:
				var target := code.decode_u16(pc)
				pc += 2
				if _pop() == 0.0:
					pc = target
			Op.JUMP:
				pc = code.decode_u16(pc)
			Op.GET_HEALTH:
				var who := int(_pop())
				if _error == "":
					_push(api.get_health(who))
			Op.DAMAGE, Op.HEAL:
				var amount := _pop()
				var who := int(_pop())
				if _error == "":  # never call the game with values from a broken stack
					if op == Op.DAMAGE:
						api.damage(who, amount)
					else:
						api.heal(who, amount)
			Op.PLAY_SOUND:
				var sound_id := int(_pop())
				if _error == "":
					api.play_sound(sound_id)
			Op.END:
				return _error
			_:
				return "Bad opcode %d at %d" % [op, pc - 1]
	return _error


func _arithmetic(op: int, a: float, b: float) -> float:
	match op:
		Op.ADD: return a + b
		Op.SUB: return a - b
		Op.MUL: return a * b
		Op.DIV: return 0.0 if b == 0.0 else a / b
		_: return 1.0 if a < b else 0.0  # LESS


func _push(v: float) -> void:
	if _stack.size() == MAX_STACK:
		_error = "Stack overflow"
	else:
		_stack.push_back(v)


func _pop() -> float:
	if _stack.is_empty():
		_error = "Stack underflow"
		return 0.0
	return _stack.pop_back()
```

```cpp [Unreal (C++)]
// SpellVM.h
#pragma once

#include "CoreMinimal.h"

enum class ESpellOp : uint8
{
	Push,          // next 4 bytes: a float literal
	Add, Sub, Mul, Div,
	Less,          // pop b, a → push (a < b ? 1 : 0)
	JumpIfZero,    // next 2 bytes: target offset; pop condition
	Jump,          // next 2 bytes: target offset
	GetHealth,     // pop who (0 = caster, 1 = target) → push health
	Damage,        // pop amount, who
	Heal,          // pop amount, who
	PlaySound,     // pop sound id
	End,
};

class ISpellApi                            // the ONLY things bytecode can do in the game
{
public:
	virtual ~ISpellApi() = default;
	virtual float GetHealth(int32 Who) = 0;
	virtual void Damage(int32 Who, float Amount) = 0;
	virtual void Heal(int32 Who, float Amount) = 0;
	virtual void PlaySound(int32 SoundId) = 0;
};

namespace SpellVM
{
	// Unreal builds without C++ exceptions, so errors come back as a message (empty = success).
	FString Run(TConstArrayView<uint8> Code, ISpellApi& Api);
}

// SpellVM.cpp
#include "SpellVM.h"

namespace
{
	constexpr int32 MaxStack = 64;
	constexpr int32 MaxInstructions = 10'000;              // sandbox limits

	template <typename T>
	bool ReadOperand(TConstArrayView<uint8> Code, int32& Pc, T& Out)
	{
		if (Pc + int32(sizeof(T)) > Code.Num()) return false;
		FMemory::Memcpy(&Out, Code.GetData() + Pc, sizeof(T));
		Pc += sizeof(T);
		return true;
	}
}

FString SpellVM::Run(TConstArrayView<uint8> Code, ISpellApi& Api)
{
	float Stack[MaxStack];
	int32 Sp = 0, Pc = 0, Executed = 0;
	FString Error;

	auto Pop = [&]() -> float
	{
		if (Sp > 0) return Stack[--Sp];
		Error = TEXT("Stack underflow");
		return 0.f;
	};
	auto Push = [&](float V)
	{
		if (Sp < MaxStack) Stack[Sp++] = V;
		else Error = TEXT("Stack overflow");
	};

	while (Pc < Code.Num() && Error.IsEmpty())
	{
		if (++Executed > MaxInstructions) return TEXT("Spell ran too long");

		const ESpellOp Op = static_cast<ESpellOp>(Code[Pc++]);
		switch (Op)
		{
		case ESpellOp::Push:       { float V; if (!ReadOperand(Code, Pc, V)) return TEXT("Truncated literal"); Push(V); break; }
		case ESpellOp::Add:        { const float B = Pop(), A = Pop(); Push(A + B); break; }
		case ESpellOp::Sub:        { const float B = Pop(), A = Pop(); Push(A - B); break; }
		case ESpellOp::Mul:        { const float B = Pop(), A = Pop(); Push(A * B); break; }
		case ESpellOp::Div:        { const float B = Pop(), A = Pop(); Push(B == 0.f ? 0.f : A / B); break; }
		case ESpellOp::Less:       { const float B = Pop(), A = Pop(); Push(A < B ? 1.f : 0.f); break; }
		case ESpellOp::JumpIfZero: { uint16 Target; if (!ReadOperand(Code, Pc, Target)) return TEXT("Truncated jump"); if (Pop() == 0.f) Pc = Target; break; }
		case ESpellOp::Jump:       { uint16 Target; if (!ReadOperand(Code, Pc, Target)) return TEXT("Truncated jump"); Pc = Target; break; }
		// Never call the game with values from a broken stack.
		case ESpellOp::GetHealth:  { const int32 Who = int32(Pop()); if (Error.IsEmpty()) Push(Api.GetHealth(Who)); break; }
		case ESpellOp::Damage:     { const float Amount = Pop(); const int32 Who = int32(Pop()); if (Error.IsEmpty()) Api.Damage(Who, Amount); break; }
		case ESpellOp::Heal:       { const float Amount = Pop(); const int32 Who = int32(Pop()); if (Error.IsEmpty()) Api.Heal(Who, Amount); break; }
		case ESpellOp::PlaySound:  { const int32 Id = int32(Pop()); if (Error.IsEmpty()) Api.PlaySound(Id); break; }
		case ESpellOp::End:        return Error;
		default:                   return FString::Printf(TEXT("Bad opcode %d at %d"), int32(Op), Pc - 1);
		}
	}
	return Error;
}
```

### A tiny assembler

In practice bytecode is generated from a text language or a node graph; this builder writes it by hand.

::: code-group

```csharp [Unity (C#)]
using System;
using System.Collections.Generic;

public class SpellAssembler
{
    readonly List<byte> code = new();
    public SpellAssembler Emit(Op op) { code.Add((byte)op); return this; }
    public SpellAssembler Push(float v) { Emit(Op.Push); code.AddRange(BitConverter.GetBytes(v)); return this; }
    public int Here => code.Count;
    public int JumpIfZeroPlaceholder() { Emit(Op.JumpIfZero); code.Add(0); code.Add(0); return code.Count - 2; }
    public void Patch(int at, int target) { var b = BitConverter.GetBytes((ushort)target); code[at] = b[0]; code[at + 1] = b[1]; }
    public byte[] Build() => code.ToArray();
}

public static class ExampleSpells
{
    // "Deal 10 to the target, heal self 5, and if self health < 30, play sound 7"
    public static byte[] DrainAndWarn()
    {
        var asm = new SpellAssembler()
            .Push(1).Push(10).Emit(Op.Damage)              // Damage(target, 10)
            .Push(0).Push(5).Emit(Op.Heal)                 // Heal(caster, 5)
            .Push(0).Emit(Op.GetHealth).Push(30).Emit(Op.Less);   // caster health < 30 ?
        int patch = asm.JumpIfZeroPlaceholder();            // if not, skip the sound
        asm.Push(7).Emit(Op.PlaySound);
        asm.Patch(patch, asm.Here);
        asm.Emit(Op.End);
        return asm.Build();                                 // store in an asset, send over the network, share as a mod
    }
}
```

```gdscript [Godot (GDScript)]
# spell_assembler.gd
class_name SpellAssembler
extends RefCounted

var _code := PackedByteArray()

var here: int:
	get:
		return _code.size()


func emit(op: SpellVM.Op) -> SpellAssembler:
	_code.append(op)
	return self


func push(v: float) -> SpellAssembler:
	emit(SpellVM.Op.PUSH)
	var at := _code.size()
	_code.resize(at + 4)
	_code.encode_float(at, v)
	return self


func jump_if_zero_placeholder() -> int:
	emit(SpellVM.Op.JUMP_IF_ZERO)
	_code.resize(_code.size() + 2)
	return _code.size() - 2


func patch(at: int, target: int) -> void:
	_code.encode_u16(at, target)


func build() -> PackedByteArray:
	return _code
```

```cpp [Unreal (C++)]
// SpellAssembler.h
#pragma once

#include "SpellVM.h"

class FSpellAssembler
{
public:
	FSpellAssembler& Emit(ESpellOp Op) { Code.Add(static_cast<uint8>(Op)); return *this; }
	FSpellAssembler& Push(float V) { Emit(ESpellOp::Push); Append(V); return *this; }
	int32 Here() const { return Code.Num(); }
	int32 JumpIfZeroPlaceholder() { Emit(ESpellOp::JumpIfZero); Append(uint16(0)); return Code.Num() - 2; }
	void Patch(int32 At, int32 Target) { const uint16 T = uint16(Target); FMemory::Memcpy(Code.GetData() + At, &T, sizeof(T)); }
	TArray<uint8> Build() const { return Code; }

private:
	template <typename T>
	void Append(T Value)
	{
		const int32 At = Code.AddUninitialized(sizeof(T));
		FMemory::Memcpy(Code.GetData() + At, &Value, sizeof(T));
	}

	TArray<uint8> Code;
};
```

**Engine notes**

- **Unity:** `BitConverter` uses the machine's byte order. That is fine on the platforms Unity targets (all little-endian), but write bytes explicitly if bytecode is exchanged with other systems.
- **Godot:** `PackedByteArray.encode_*` / `decode_*` always use little-endian, so bytecode is portable between platforms. GDScript has no exceptions, so the VM reports errors as values. GDScript itself is compiled to bytecode by the engine, but that VM is not exposed as a sandbox for player content.
- **Unreal:** C++ exceptions are off in Unreal builds, hence the error string. `memcpy` of floats assumes little-endian, which every current Unreal platform is. Blueprints already compile to bytecode run by Unreal's script VM, and the Gameplay Ability System makes abilities data (gameplay effects, tags, cues), which often removes the need for a custom VM. A VM like this one is for content that must be sandboxed or loaded at runtime, such as mods.

## When to use

- Behaviour that must be **data** but contains logic: moddable spells, user-generated content, server-pushed scripted events, level scripting.
- Sandboxing untrusted behaviour (mods, user content) with strict limits.
- Hot behaviour on IL2CPP platforms, where you cannot load new compiled code.
- Faster execution than tree-walking [interpreters](./interpreter), when many scripts run per frame.

## When not to use

- Logic that designers can express as data or simple formulas. Use [Data-Driven Design](./data-driven-design) or a small [Interpreter](./interpreter).
- When an existing embedded language fits, such as Lua or Ink. Building and maintaining your own VM and compiler is a large project.
- Behaviour only programmers write. Plain C# is faster to write, debug and profile.

## Pitfalls

- **Writing bytecode by hand.** Nobody should author raw instructions. Provide a compiler from a readable format, or a visual editor, plus a disassembler for debugging.
- **No validation.** Malformed bytecode (bad jump targets, stack underflow) crashes or corrupts the VM. Validate when loading, and keep runtime checks and limits, as above.
- **Building a general-purpose language.** Variables, functions, loops and strings quickly turn a small VM into a large project. Before going far, consider embedding an existing VM (Lua via MoonSharp, for example).
- **Debuggability.** When a spell misbehaves, designers need to see what it did. Add tracing (log each instruction and the stack) in development builds.
- **API surface is security.** Every instruction that calls the game is something mods can do. Expose only what is safe, and validate arguments (no "damage player 1,000,000").
