# Pattern Catalog

Every pattern on this site, grouped by area. Linked entries have a full page. Entries marked **planned** are listed but not written yet. Use the filter to search names, summaries and aliases. Patterns marked **Interactive** have a visualizer you can play with on their page: tick **Interactive only** to list them.

::: warning Use patterns sparingly
A pattern earns its place only when it solves a problem your game has **now**. For simple mechanics, plain code is usually the better choice. See [Keep It Simple](../keep-it-simple) before reaching for one.
:::
